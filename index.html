自作キーボード

配置ファイルの URL を別に指定

GitHub のリポジトリ（例: tadakado/tk46v6b）を入れると、keymap/ の刻印 YAML と、その layout: {dts_layout: …} が指す dtsi を取得します。開くたびに最新を取り直します。

ファイルから読む場合は、keymap-drawer の keymap parse が出す YAML（刻印）と、dtsi か keymap draw の SVG（配置）を同時に選びます。レイヤー名をそのレイヤーに切り替えるキーの刻印（例: Lower）と同じにしておくと、別レイヤーの文字は「押しながら」で示します。
